# 상권 생존 지도

**소비는 있는데 왜 못 버티는가** — BC카드 소비데이터 공모전 출품작.

점포 단위 폐업 기록과 BC카드 소비 데이터를 결합해 어떤 지역·업종이 왜 폐업 위험이 높은지 설명하고, 그 결과를 지도 기반 웹사이트로 만들었다.

- **웹사이트**: https://ahnseo0000.github.io/BC_card/
- **데이터 소스·업종 매핑**: [DATA_MAPPING.md](DATA_MAPPING.md)
- **프로젝트 기획**: [BC카드_공모전_프로젝트_계획.md](BC카드_공모전_프로젝트_계획.md)

---

## 문제의식

BC카드의 기존 서비스(상권지수, Biz Credit)는 상권을 등급으로 스냅샷하거나 개별 가맹점의 휴폐업을 예측한다. 이 프로젝트는 한 단계 더 들어가서 **지역×업종 단위로 왜 폐업 위험이 갈리는지를 요인별로 분해**하고, 그 분해가 실제로 예측력이 있는지를 여러 각도에서 검증하는 데 집중했다. 결과는 전부 통계적 연관이며 인과관계를 주장하지 않는다.

## 데이터

| 데이터 | 성격 | 쓰임 |
|---|---|---|
| BC카드 소비데이터 (대회 제공) | 시군구×업종×성별×연령×월 집계, 2026년 1~6월 | 지역·업종별 소비 구성·규모 |
| 지방행정 인허가데이터 (LOCALDATA, data.go.kr) | 일반음식점·제과점영업·휴게음식점·대규모점포 4종, 개별 점포의 인허가·폐업일자 | 생존분석의 관측 단위(결과 변수) |
| 소상공인시장진흥공단 상가정보 | 전국 상가 스냅샷 | 경쟁밀도 후보로 검토했으나 시점 문제(폐업 점포가 스냅샷에서 빠짐)로 최종 모형에는 미사용 |

LOCALDATA 4종을 정제·통합하면 214만 행(37개 컬럼)이 되고, 여기서 BC카드가 다루는 9개 업종에 매핑되는 점포를 추려 분석에 쓴다. 분석 대상은 **2026년 1월 1일 기준 영업 중이던 점포 635,536개**(한식계열·일식회집·중국음식·서양음식·스낵·제과점·편의점 7개 업종, 시군구×업종 조합 1,782개·시군구 255개)이며, 180일간 추적해 25,329건(3.99%)의 폐업을 관측했다. 대형할인점·슈퍼마켓은 표본이 작아 생존모형 대신 KM 생존곡선으로만 따로 봤다.

## 데이터 전처리

- **LOCALDATA 정제**: 날짜, 좌표, 시설 규모, 영업상태 등 컬럼별로 정제 규칙을 따로 두었다. 좌표는 영역 경계값과 주변 5개 점의 행정구역 일치 여부로 이상치 의심 플래그만 남기고 임의로 삭제하지 않았다(섬 지역의 정상적인 점포까지 날아가는 문제가 있어서, 처음에는 삭제했다가 플래그 방식으로 바꿨다).
- **행정구역 대응**: 시군구 신설·통합(화성 동탄구 등), 인천 구역 개편(검단구·서해구→서구, 영종구→중구, 제물포구→미추홀구 등)을 대응표로 반영하고, BC카드 쪽에만 있는 제물포구는 LOCALDATA의 중구+동구 데이터를 합성해 끼워 맞췄다. 최종 결합 매칭률은 99.99%.
- **프랜차이즈 판별**: 공식 라벨이 없어 브랜드 키워드 목록을 직접 구축했다(약 150개 브랜드, 한글·영문 혼용 표기와 매장명 변형까지 고려). 업종 특유의 흔한 오탐(예: "CU"가 다른 단어 안에 포함되는 경우)을 정규식으로 걸러냈다.
- **BC 소비데이터 결합**: 11개 업종을 LOCALDATA 업종 체계에 맞춰 9개로 재매핑하고, 성별·연령 조합이 소규모라 마스킹된 셀은 구성비 계산에서 제외했다.

## 생존분석 모델링

결과 변수는 폐업 여부, 분석 단위는 점포다. **2026년 1월 1일에 영업 중이던 점포를 180일간 추적**하는 단순 코호트를 기본 설계로 썼다(공모전 팀원이 처음 설계했던 78일짜리 landmark 방식은 강건성 확인용으로 병행했다).

Cox 비례위험모형을 메인으로 쓴 이유는 선형 모형이라 각 변수의 기여를 `exp(계수 × (값 − 평균))` 형태로 정확히 분해할 수 있기 때문이다. 랜덤서바이벌포레스트는 비선형 성능이 얼마나 더 나은지 비교하는 용도로 병행했다(팀원이 별도 환경에서 검증, 아직 최종 변수 구성 전부를 반영하지는 못했다).

최종 모형(M3L)은 네 블록으로 구성된다.
- **점포 특성**: 영업연수, 프랜차이즈 여부, 입지(상권 중심지까지 거리), 점포 규모·다중이용시설 여부
- **지역의 최근 폐업 흐름**: 그 시군구의 직전 1년 폐업률, 그리고 이웃 시군구들의 직전 1년 폐업률(k-최근접 공간 가중)
- **BC카드 소비 구성**: 해당 시군구×업종의 성별·연령 구성비
- **업종 더미**

이 모형에 도달하기까지 M0(업종만)부터 M2(+점포 특성), M2h(+지역 폐업률), M3(+BC 구성), M3L(+이웃 폐업률)까지 단계적으로 변수를 더하며 각 단계의 기여를 따로 검증했다.

## 모형 검증

같은 데이터로 찾은 패턴은 우연일 수 있어 여러 각도로 검증했다.

**교차검증.** 시군구×업종 조합(그룹) 단위 5겹 교차검증과 시군구 단위 5겹 교차검증을 모두 돌렸다. 미학습 그룹에 대한 순위 일치도(Spearman)는 모형을 단계적으로 키울수록 M2 0.501 → M2h 0.534 → M3 0.562로 올라갔고, 점포 단위 판별력(C-index)도 0.621 → 0.633 → 0.635로 개선됐다. 지역의 직전 폐업률을 추가했을 때의 개선폭(+0.032, 95% 신뢰구간이 0을 포함하지 않음)은 뚜렷했지만, BC 구성을 추가했을 때의 개선폭(+0.029, 신뢰구간 [-0.001, 0.056])은 경계선에 걸렸다.

**교란 변수 점검.** BC 연령 구성이 사실은 "상권 유형"(신도시 vs 구도심)의 대리 지표일 뿐인지 확인했다. 시군구로 층화한 모형(같은 시군구 안에서만 비교)에서는 연령 구성의 기여가 거의 사라졌다(증분 -0.026, 신뢰구간이 0을 포함). 즉 연령 구성은 "어느 지역인가"를 가르는 데는 쓰이지만, 같은 지역 안에서 "어느 업종이 더 위험한가"는 가르지 못했다.

**공간 자기상관.** 모형이 설명하지 못한 잔차가 지리적으로 뭉쳐 있는지 Moran's I로 확인했다. 기본 모형(M2h)의 잔차는 공간적으로 뚜렷하게 뭉쳐 있었는데(I=0.241, k=5 이웃 기준), 이웃 시군구의 직전 1년 폐업률을 변수로 추가하자 뭉침이 통계적으로 사라졌다(I=0.023, p=0.23). 그래프 신경망 같은 복잡한 공간 모형 없이 간단한 이웃 변수 하나로 해결된 셈이라, 별도의 공간 모델링 단계는 생략했다.

**전향(시간 밖) 검증.** 1~6월 데이터로 학습한 모형이 실제 미래를 맞히는지가 가장 중요한 검증이다. 6월 30일에 영업 중이던 점포 634,490개를 9월 16일까지 78일 더 추적해서, 1~6월로만 학습한 모형의 예측과 비교했다. 점포 단위 C-index는 0.627로 학습 기간 성능(0.635)과 비슷하게 유지됐고, 모형이 매긴 위험 점수 상위 10% 점포가 실제 폐업의 20.0%를, 상위 30%가 48.3%를 차지했다(위험 10분위 중 최상위 구간의 실제 폐업률은 최하위 구간의 약 4.3배). 또한 "그냥 상반기 폐업률을 그대로 유지한다"는 단순 기준보다 모형이 유의하게 나았다(개선폭 +0.077, 신뢰구간 [0.013, 0.139]).

## 요인 분해와 상권 유형

Cox 모형의 선형예측값을 요인 블록별로 정확히 쪼개서(오차 10⁻¹⁵ 수준) "이 상권이 평균 대비 몇 배 위험한지"와 "그중 어떤 요인이 얼마나 기여하는지"를 함께 제시한다. 예를 들어 위험도가 가장 높은 축에 속하는 서울 마포구 제과점 조합은 평균 대비 약 1.9배 위험한데, 이 중 상당 부분이 짧은 평균 영업연수와 지역의 최근 폐업 흐름에서 온다.

다만 SHAP류 분해가 보여주는 "중요도"와 실제로 예측에 필요한 정도는 다를 수 있어서, 블록을 하나씩 빼고 모형을 다시 학습해 성능이 얼마나 떨어지는지로 교차 확인했다. 그 결과 점포 단위 판별력은 영업연수·점포 규모·프랜차이즈 여부가 대부분 만들고, 지역 간 순위는 이웃 지역 폐업 흐름과 BC 연령 구성이 기여하며, 같은 지역 안에서의 순위는 업종 차이가 가장 크게 만든다는 걸 확인했다.

이 요인 프로필(영업연수, 프랜차이즈 비중, 점포 규모, 지역 폐업 흐름)이 비슷한 조합끼리 K-평균으로 묶어 **5개 상권 유형**을 만들었다(군집 품질 실루엣 계수 0.345로, 경계가 뚜렷하진 않지만 해석에 쓸 수 있는 수준).

| 유형 | 특징 | 점포 비중 | 폐업 비중 | 평균 위험도 |
|---|---|---|---|---|
| A | 프랜차이즈 많음·폐업 잦은 지역·신생 점포 많음 | 12.9% | 17.3% | 1.38배 |
| B | 폐업 잦은 지역·개인 점포 중심 | 36.7% | 41.6% | 1.15배 |
| C | 폐업 드문 지역·신생 점포 많음 | 11.1% | 12.0% | 1.05배 |
| D | 프랜차이즈 많음·대형/다중이용 점포 | 5.2% | 4.3% | 0.89배 |
| E | 폐업 드문 지역·개인 점포 중심·오랜 점포 많음 | 34.1% | 24.8% | 0.79배 |

## 단기 소비 수요 예측

생존분석은 "왜 폐업하는가"를 설명하지만, BC카드 실무에서는 "앞으로 소비가 어떻게 움직일지"도 중요한 질문이다. 그래서 그룹(시군구×업종) 단위로 **1~4월 정보만으로 5~6월 평균 소비를 예측**하는 모델을 따로 만들고 검증했다. BC 데이터가 6개월치뿐이라 계절성까지 반영하는 정식 수요예측은 불가능했고, 그 한계를 인정한 채로 "짧은 구간 추세와 점포·고객 구성 정보가 실제로 예측에 도움이 되는가"를 검정하는 쪽으로 설계했다.

세 가지 방법을 그룹 5겹 교차검증(미학습 그룹 기준)으로 비교했다.

| 방법 | 설명 | MAPE | 그룹 순위 일치도 |
|---|---|---|---|
| 지속성(persistence) | 4월 값을 5~6월 예측치로 그대로 사용 | 8.8% | 0.998 |
| 추세 연장(trend) | 1~4월 로그 소비의 선형 추세를 연장 | 11.1% | 0.996 |
| **구성 반영 모형(model)** | 지속성 + 추세 + 점포·고객 구성(프랜차이즈 비중, 평균 영업연수, 다중이용 비중, 그룹 규모)을 Ridge 회귀로 결합 | **6.8%** | 0.998 |

흥미로운 점은 단순히 "직전 달 값을 유지한다"는 지속성 예측만으로도 이미 MAPE 8.8%로 꽤 정확했다는 것이다. 이는 모형이 뛰어나서가 아니라 시군구×업종 단위로 집계하다 보니 표본이 커서 월별 변동 자체가 크지 않기 때문이다. 오히려 단순 추세 연장은 짧은 구간의 잡음을 추세로 오인해 지속성보다 더 나빴다. 점포·고객 구성 정보를 더한 모형은 이 안정적인 베이스라인 대비로도 오차를 8.8%→6.8%(상대 약 23% 감소)까지 줄였는데, 이는 매장 분석과 고객 구성 분석 결과를 실제 수요 예측에 결합했을 때 유의미하게 보탬이 된다는 근거다.

추가로, 1~4월 소비 증가 추세가 가파른 그룹일수록 폐업 위험이 낮은지도 확인했다. 상관은 -0.071로 거의 없었다 — 즉 "소비가 늘고 있다고 해서 더 안전해지는 것은 아니다"는 걸 다시 한 번 보여준다.

## 고객 분석: 연령 구성 변화

BC카드 데이터는 시군구×업종 단위 집계라 개인 고객을 추적할 순 없지만, 그룹 단위에서 상반기(1~3월) 대비 하반기(4~6월)에 고객 연령 구성이 어떻게 움직였는지는 볼 수 있다. 금액 가중 평균 연령 코드를 반기별로 계산해 변화량을 구하고(표본이 작은 그룹은 변화량이 불안정해 상·하반기 모두 거래 300건 이상인 1,788개 그룹만 사용), 업종별 평균과 위험도와의 관계를 봤다.

전 업종에서 평균적으로 연령 코드가 소폭 상승(고령층 비중이 살짝 느는 방향)했는데, 중국음식·편의점·스낵은 변화가 작았고(+0.02~0.04) 한식계열·제과점·일식회집은 상대적으로 컸다(+0.05 안팎). 변화량을 3분위로 나눠 보면 고령화 방향으로 이동한 그룹의 평균 위험도(0.944)가 젊어지는 방향으로 이동한 그룹(1.077)보다 낮았지만, 상관계수는 -0.122로 약한 수준이라 강한 근거로 보긴 어렵다. 가장 크게 바뀐 그룹은 대체로 소도시·군 지역의 일식회집처럼 표본이 상대적으로 작은 조합에 몰려 있어 해석에 주의가 필요하다.

## 핵심 결과 요약

- 그룹 간 폐업률 차이는 업종보다 지역(시군구) 차이가 훨씬 크다(설명력 기준 약 4배).
- 점포 단위 위험은 영업연수·프랜차이즈·점포 규모가, 지역 간 위험 차이는 그 지역과 이웃 지역의 최근 폐업 흐름이 가장 크게 설명한다.
- BC카드 성별·연령 구성은 "어떤 유형의 지역인가"를 보여주는 맥락 정보에 가깝다 — 같은 시군구 안에서는 폐업 위험을 가르지 못했다.
- 모형은 6월 이후 실제로 일어난 폐업도 어느 정도 맞혔고(전향 검증 C-index 0.627), 위험 상위 10% 점포가 실제 폐업의 20%를 차지했다.
- 단기 소비 추이는 점포·고객 구성 정보를 더했을 때 예측 오차가 의미 있게 줄었지만(23% 감소), 소비 증가 추세 자체가 폐업 위험과 강하게 연관되진 않았다.
- 고객 연령 구성의 변화는 폐업 위험과 약하게만 연관됐다.

## 웹사이트

- **지도 탐색**: 시군구를 버블로 표시하고 위험도·실제 폐업률·상권 유형별로 색을 바꿔 볼 수 있다. 업종 필터, 자연어에 가까운 검색("동탄 서양음식", "한식 위험한 곳"), 지역 선택 시 나오는 요인별 분해, BC카드 소비 구성, 상권 유형 설명, 개업 연수·프랜차이즈 여부를 입력하면 상대적 위험도를 즉시 계산해주는 진단 기능이 있다.
- **상권 분석**: 시군구 프로필, 두 지역 비교, 위험·안전 순위, 상권 유형별 통계.
- **모형 근거**: 어떤 요인이 왜 중요한지, 교차검증·전향검증 결과, 데이터의 한계.
- 검색과 설명 문구는 LLM이 아니라 규칙 기반으로 만들어 숫자가 분석 결과와 항상 일치하도록 했다.
- 단기 소비 수요 예측과 고객 연령 구성 변화 분석은 아직 사이트에 반영하지 않았고, 현재는 스크립트와 결과 수치로만 존재한다.

## 기술 스택

Python(pandas, lifelines, scikit-survival, scikit-learn, scipy), Cox 비례위험모형 / 랜덤서바이벌포레스트, 공간분석(Moran's I, pyproj, KD-Tree), 정적 웹(순수 HTML/CSS/JS + Leaflet), GitHub Pages 배포.

## 재현 방법

원자료(BC카드 데이터, LOCALDATA 4종)는 용량 문제로 저장소에 포함하지 않았다. `data/`에 원자료를 두고 아래 순서로 실행한다.

```
python preprocess_bc.py
python preprocess_localdata.py
python join_datasets.py

python bc_scale_check.py        # 교차검증, 그룹 특성 — 다른 스크립트가 이 결과를 재사용하므로 가장 먼저 실행
python explain_final.py         # 최종 모형 요인 분해
python risk_decomp.py
python moran_residuals.py
python group_types.py
python forward_validation.py
python demand_forecast.py
python customer_analysis.py

python prep_site_data.py
python build_site.py            # docs/index.html 생성 — GitHub Pages가 서비스하는 파일
```

Python 3.13 환경은 `requirements-py313.txt`를, 랜덤서바이벌포레스트(scikit-survival)는 별도의 Python 3.9 환경(`requirements.txt`)을 쓴다.

## 한계

- BC카드 데이터는 시군구×업종 단위 집계라 점포별 매출이 아니다. 더 세밀한 데이터가 있다면 결과가 달라질 수 있다.
- 관측 기간이 6개월(소비 데이터)~9개월(폐업 추적)로 짧아 계절성은 다루지 못한다.
- 프랜차이즈 여부는 자체 구축한 브랜드 목록 기반이라 일부 누락 가능성이 있다.
- 랜덤서바이벌포레스트는 아직 최종 모형과 동일한 변수 구성으로 재검증하지 못했다.
- 연령 코드(1~6)는 오름차순 연령대라고 가정했을 뿐, 공식 정의를 확인하지 못했다.
