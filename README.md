# 상권 생존 지도

**소비는 있는데 왜 못 버티는가** — BC카드 소비데이터 공모전 출품작.

점포 단위 폐업 기록과 BC카드 소비 데이터를 결합해 어떤 지역·업종이 왜 폐업 위험이 높은지 요인별로 설명하는 생존분석 모델을 만들고, 미래 시점 데이터로 실제 예측력까지 검증한 뒤 지도 기반 웹사이트로 서비스했다.

## 프로젝트 개요

BC카드의 기존 서비스(상권지수, Biz Credit)는 상권을 등급으로 스냅샷하거나 개별 가맹점의 휴폐업을 예측한다. 이 프로젝트는 한 단계 더 들어가서 **지역×업종 단위로 왜 폐업 위험이 갈리는지를 요인별로 분해**하고, 그 분해가 실제로 미래 시점에서도 예측력이 있는지를 검증했다. 생존분석(Cox 비례위험모형)으로 "왜"를 설명하고, 같은 데이터로 단기 소비 수요까지 예측해 분석 결과를 실무에 바로 쓸 수 있는 형태로 만든 것이 핵심이다.

## 데이터

| 데이터 | 성격 | 쓰임 |
|---|---|---|
| BC카드 소비데이터 (대회 제공) | 시군구×업종×성별×연령×월 집계, 2026년 1~6월 | 지역·업종별 소비 구성·규모, 수요 예측의 원천 |
| 지방행정 인허가데이터 (LOCALDATA, data.go.kr) | 일반음식점·제과점영업·휴게음식점·대규모점포 4종, 개별 점포의 인허가·폐업일자 | 생존분석의 관측 단위(결과 변수) |
| 소상공인시장진흥공단 상가정보 | 전국 상가 스냅샷 | 경쟁밀도 참고 자료로 검토 |

LOCALDATA 4종을 정제·통합한 214만 행(37개 컬럼) 중 BC카드 9개 업종에 매핑되는 점포를 추려 분석에 썼다. 분석 대상은 **2026년 1월 1일 기준 영업 중이던 점포 635,536개**(한식계열·일식회집·중국음식·서양음식·스낵·제과점·편의점 7개 업종, 시군구×업종 조합 1,782개·시군구 255개)이며, 180일간 추적해 25,329건(3.99%)의 폐업을 관측했다.

## 데이터 전처리

- **좌표 정제**: 좌표 이상치는 영역 경계값과 주변 점들의 행정구역 일치 여부로 의심 사례만 플래그 처리하고 데이터는 보존했다. 섬 지역처럼 정상적인데도 통계적으로는 특이해 보이는 사례까지 삭제되는 걸 막기 위한 설계다.
- **행정구역 통합**: 시군구 신설·통합(화성 동탄구 등), 인천 구역 개편(검단구·서해구→서구, 영종구→중구, 제물포구→미추홀구 등)을 전부 대응표로 반영해 **99.99% 매칭률**로 BC카드 데이터와 결합했다.
- **프랜차이즈 식별**: 공식 라벨이 없어 약 150개 브랜드의 키워드 목록을 직접 구축하고, 흔한 오탐(예: "CU"가 다른 단어에 포함되는 경우)을 정규식으로 걸러냈다.
- **BC 소비데이터 정제**: 11개 업종을 LOCALDATA 체계에 맞춰 9개로 재매핑하고, 소규모 셀 마스킹을 구성비 계산에서 적절히 처리했다.

## 생존분석 모델링

결과 변수는 폐업 여부, 분석 단위는 점포다. **2026년 1월 1일에 영업 중이던 점포를 180일간 추적**하는 코호트를 설계했다(비교용으로 78일짜리 landmark 설계도 함께 검증).

Cox 비례위험모형을 메인으로 선택한 이유는 선형 모형이라 각 변수의 기여를 `exp(계수 × (값 − 평균))` 형태로 **정확하게 분해**할 수 있기 때문이다. 랜덤서바이벌포레스트는 비선형 모형이 추가로 설명하는 부분이 있는지 비교하는 용도로 병행했다.

최종 모형(M3L)은 네 블록으로 구성된다.
- **점포 특성**: 영업연수, 프랜차이즈 여부, 입지(상권 중심지까지 거리), 점포 규모·다중이용시설 여부
- **지역의 최근 폐업 흐름**: 해당 시군구와 이웃 시군구들의 직전 1년 폐업률(공간 가중)
- **BC카드 소비 구성**: 해당 시군구×업종의 성별·연령 구성비
- **업종**

변수를 단계적으로 추가하며(M0 업종만 → M2 점포 특성 → M2h 지역 폐업률 → M3 BC 구성 → M3L 이웃 폐업률) 각 단계가 실제로 설명력을 높이는지 매번 검증했다.

## 모형 검증 — 네 가지 방식으로 신뢰성 확보

분석에서 가장 공들인 부분이다. 하나의 검증으로 끝내지 않고 교차검증, 교란변수 통제, 공간구조 점검, 그리고 **미래 시점 실측 검증**까지 네 겹으로 모형의 신뢰성을 확인했다.

**1) 교차검증.** 시군구×업종 그룹 단위 5겹 교차검증으로 미학습 그룹에 대한 일반화 성능을 확인했다. 변수를 단계적으로 추가할수록 순위 일치도(Spearman)가 0.501 → 0.534 → 0.562로, 점포 단위 판별력(C-index)이 0.621 → 0.633 → 0.635로 꾸준히 개선됐다. 특히 지역의 최근 폐업률을 추가했을 때의 개선폭(+0.032, 95% 신뢰구간이 0을 포함하지 않음)이 뚜렷해, **지역의 최근 동향이 강력한 예측 신호**라는 걸 확인했다.

**2) 교란변수 통제.** BC 연령 구성이 진짜 설명력을 갖는지, 아니면 상권 유형(신도시 vs 구도심)의 대리 신호일 뿐인지 시군구로 층화한 모형으로 분리해서 확인했다. 이 과정에서 "BC 연령 구성은 같은 지역 안의 업종 간 차이보다 지역 자체를 구분하는 신호로 더 강하게 작동한다"는 걸 명확히 했다 — 변수의 역할을 정확히 규명한 것 자체가 분석의 신뢰도를 높인 성과다.

**3) 공간구조 점검.** 모형의 잔차가 지리적으로 패턴을 남기는지 Moran's I로 확인했다. 기본 모형의 잔차에는 뚜렷한 공간 패턴이 있었지만(I=0.241), **이웃 시군구의 폐업 흐름을 변수로 추가하는 것만으로 그래프 신경망 같은 복잡한 공간 모형 없이 패턴을 해소**했다(I=0.023). 간단한 변수 설계로 복잡한 문제를 효율적으로 풀어낸 부분이다.

**4) 전향(미래 시점) 검증 — 가장 강력한 증거.** 1~6월 데이터로만 학습한 모형이 실제 미래를 맞히는지 확인했다. 6월 30일에 영업 중이던 점포 634,490개를 9월 16일까지 78일 더 추적해서 모형이 사전에 매긴 위험 점수와 대조했다.

| 지표 | 결과 |
|---|---|
| 점포 단위 판별력(C-index) | 0.627 (학습 기간 0.635와 거의 동일하게 유지) |
| 위험 상위 10% 점포가 차지한 실제 폐업 비중 | 20.0% |
| 위험 상위 30% 점포가 차지한 실제 폐업 비중 | 48.3% |
| 위험 최상위 10분위 vs 최하위 10분위 실제 폐업률 | 약 4.3배 차이 |
| "직전 폐업률을 그대로 유지" 베이스라인 대비 개선 | +0.077 (95% 신뢰구간 [0.013, 0.139], 유의) |

학습에 전혀 쓰지 않은 미래 3개월의 실제 결과로 모형 성능이 입증됐다는 게 핵심이다. 위험 점수 상위 10%에만 집중해도 실제 폐업의 5분의 1을 사전에 짚어낼 수 있다는 뜻이다.

## 요인 분해와 상권 유형 — "왜 위험한가"에 대한 답

Cox 모형의 선형예측값을 요인 블록별로 정확히 쪼개서(오차 10⁻¹⁵ 수준) "이 상권이 평균 대비 몇 배 위험한지"와 "어떤 요인이 얼마나 기여하는지"를 숫자로 제시한다. 예를 들어 위험도가 가장 높은 축에 속하는 서울 마포구 제과점 조합은 평균 대비 약 1.9배 위험한데, 이 중 상당 부분이 짧은 평균 영업연수와 지역의 최근 폐업 흐름에서 온다.

SHAP류 분해가 보여주는 "중요도"가 실제 예측 기여와 일치하는지도 블록을 하나씩 제거해 재학습하는 방식으로 교차 확인했다. 결론적으로 **점포 단위 판별력은 영업연수·점포 규모·프랜차이즈가, 지역 간 순위는 이웃 지역 폐업 흐름과 BC 연령 구성이, 같은 지역 안의 업종 간 순위는 업종 특성 자체가** 가장 크게 만든다는 걸 확인했다 — 각 변수가 어느 층위에서 힘을 발휘하는지 명확히 구분해낸 것이다.

이 요인 프로필(영업연수, 프랜차이즈 비중, 점포 규모, 지역 폐업 흐름)을 기준으로 전체 조합을 K-평균으로 묶어 **5개 상권 유형**을 도출했다.

| 유형 | 특징 | 점포 비중 | 폐업 비중 | 평균 위험도 |
|---|---|---|---|---|
| A | 프랜차이즈 많음·폐업 잦은 지역·신생 점포 많음 | 12.9% | 17.3% | 1.38배 |
| B | 폐업 잦은 지역·개인 점포 중심 | 36.7% | 41.6% | 1.15배 |
| C | 폐업 드문 지역·신생 점포 많음 | 11.1% | 12.0% | 1.05배 |
| D | 프랜차이즈 많음·대형/다중이용 점포 | 5.2% | 4.3% | 0.89배 |
| E | 폐업 드문 지역·개인 점포 중심·오랜 점포 많음 | 34.1% | 24.8% | 0.79배 |

유형 A·B에 전체 점포의 절반이 속하는데 실제 폐업의 59%가 이 두 유형에서 나왔다 — 위험이 소수의 유형에 몰려 있다는 걸 보여주는 실용적인 결과다.

## 단기 소비 수요 예측

생존분석이 "왜 폐업하는가"를 설명한다면, 이 모듈은 "앞으로 소비가 어떻게 움직일지"를 예측해 분석 결과를 수요 예측·마케팅 의사결정에도 쓸 수 있게 확장한 것이다. 그룹(시군구×업종) 단위로 **1~4월 정보만으로 5~6월 평균 소비를 예측**하는 모델을 설계하고, 미학습 그룹 기준 5겹 교차검증으로 성능을 검증했다.

세 가지 방법을 비교했다.

| 방법 | 설명 | MAPE | 그룹 순위 일치도 |
|---|---|---|---|
| 지속성(persistence) | 4월 값을 그대로 사용하는 전통적 베이스라인 | 8.8% | 0.998 |
| 추세 연장(trend) | 1~4월 소비의 선형 추세를 연장 | 11.1% | 0.996 |
| **구성 반영 모형** | 지속성 + 추세 + 점포·고객 구성(프랜차이즈 비중, 평균 영업연수, 다중이용 비중, 그룹 규모)을 Ridge 회귀로 결합 | **6.8%** | **0.998** |

**핵심 성과는 베이스라인 대비 예측 오차를 23% 줄인 것이다(MAPE 8.8%→6.8%).** 시군구×업종 집계 단위라 월별 소비가 원래 안정적이어서 단순 베이스라인도 높은 정확도를 보였는데, 여기에 점포·고객 구성 정보(매장 분석·고객 분석 결과)를 결합한 모형이 이미 강력한 베이스라인을 유의미하게 추가로 개선했다는 점에서 **매장·고객 데이터가 실제 수요 예측에 기여한다는 것을 정량적으로 입증**했다. 교차검증된 수치이므로 특정 샘플에 과적합된 결과가 아니다.

추가로 1~4월 소비 증가 추세와 폐업 위험의 관계도 살펴봤는데, 상관이 거의 없었다(-0.071) — "소비가 늘고 있어도 생존이 자동으로 보장되진 않는다"는, 생존분석 결과와 일관된 통찰을 추가로 확인한 것이다.

## 고객 분석: 연령 구성 변화

BC카드 데이터로 그룹 단위에서 상반기(1~3월) 대비 하반기(4~6월)에 고객 연령 구성이 어떻게 움직였는지 분석했다. 금액 가중 평균 연령 코드를 반기별로 계산해 변화량을 구하고(표본이 충분한 1,788개 그룹 기준), 업종별 패턴과 위험도와의 관계를 봤다.

전 업종에서 평균적으로 연령 코드가 소폭 상승(고령층 비중이 살짝 느는 방향)했고, 업종별로 변화 폭에 뚜렷한 차이가 있었다 — 중국음식·편의점·스낵은 변화가 작았고(+0.02~0.04), 한식계열·제과점·일식회집은 상대적으로 컸다(+0.05 안팎). 고령화 방향으로 이동한 그룹의 평균 위험도(0.944)가 젊어지는 방향으로 이동한 그룹(1.077)보다 낮은 경향도 확인했다.

## 핵심 성과 요약

- **지역이 업종보다 폐업률 차이를 훨씬 크게 가른다**는 걸 통계적으로 입증했다(설명력 기준 약 4배 차이).
- 생존분석 모형을 **네 가지 독립적인 방식으로 검증**해 신뢰도를 확보했고, 특히 **미래 3개월 실측 데이터로 예측력을 증명**했다(C-index 0.627, 위험 상위 10%가 실제 폐업의 20% 포착).
- 요인 분해로 **어떤 변수가 어느 층위(점포 vs 지역 vs 업종)에서 작동하는지**를 정밀하게 구분해냈다.
- 요인 프로필 기반으로 **5개 상권 유형**을 도출해 위험이 소수 유형에 집중된다는 실용적 인사이트를 제시했다.
- 단기 소비 수요 예측 모델을 구축해 **베이스라인 대비 오차 23% 감소**를 교차검증으로 입증했다 — 매장·고객 데이터가 수요 예측에 실제로 기여함을 정량적으로 보여준 결과다.
- 이 모든 분석을 **서버 없는 정적 웹사이트**로 구현해, 분석에서 서비스까지 전체 파이프라인을 완성했다.

## 웹사이트

- **지도 탐색**: 시군구를 버블로 표시하고 위험도·실제 폐업률·상권 유형별로 색을 바꿔 볼 수 있다. 업종 필터, 자연어에 가까운 검색("동탄 서양음식", "한식 위험한 곳"), 지역 선택 시 나오는 요인별 분해, BC카드 소비 구성, 상권 유형 설명, 개업 연수·프랜차이즈 여부를 입력하면 상대적 위험도를 즉시 계산해주는 진단 기능이 있다.
- **상권 분석**: 시군구 프로필, 두 지역 비교, 위험·안전 순위, 상권 유형별 통계.
- **모형 근거**: 어떤 요인이 왜 중요한지, 교차검증·전향검증 결과, 데이터의 한계.
- 검색과 설명 문구는 LLM이 아니라 규칙 기반으로 만들어 숫자가 분석 결과와 항상 일치하도록 설계했다.

## 재현 방법

원자료(BC카드 데이터, LOCALDATA 4종)는 용량 문제로 저장소에 포함하지 않았다. `data/`에 원자료를 두고 아래 순서로 실행한다.

```
python preprocess_bc.py
python preprocess_localdata.py
python join_datasets.py

python bc_scale_check.py        # 교차검증, 그룹 특성 — 다른 스크립트가 이 결과를 재사용하므로 가장 먼저 실행
python explain_final.py         # 최종 모형 요인 분해
python risk_decomp.py
python moran_residuals.py
python group_types.py
python forward_validation.py
python demand_forecast.py
python customer_analysis.py

python prep_site_data.py
python build_site.py            # docs/index.html 생성 — GitHub Pages가 서비스하는 파일
```

Python 3.13 환경은 `requirements-py313.txt`를, 랜덤서바이벌포레스트(scikit-survival)는 별도의 Python 3.9 환경(`requirements.txt`)을 쓴다.

## 한계와 다음 단계

- BC카드 데이터는 시군구×업종 단위 집계라 점포별 매출은 아니다. 점포 단위 매출 데이터가 결합되면 더 정밀한 예측이 가능할 것이다.
- 소비 데이터가 6개월치라 계절성을 반영한 장기 수요 예측은 다음 단계 과제다.
- 랜덤서바이벌포레스트에 최종 변수 구성을 전부 반영하는 작업이 남아 있다.
- 프랜차이즈 여부는 자체 구축한 브랜드 목록 기반이라 지속적인 업데이트가 필요하다.
